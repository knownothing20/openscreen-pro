## 2. 设置链：上一轮卡在哪，这轮怎么过

上一轮我靠字符串替换猜"哪个默认值对象"，tsc 每次都说"这个对象里没有那个键"。这轮先把对象读清楚，
确认了三条事实——它们不能靠猜：

1. **权威来源是 `DEFAULT_PROJECT_APPEARANCE.cursor`**（`projectDefaults.ts:326`），它的类型是接口
   `ProjectAppearanceDefaults`（`:279`）里**内联**写的 cursor 结构。
2. **`DEFAULT_CURSOR_SETTINGS`**（`video-editor/editorDefaults.ts`）只是引用上一层的
   `.cursor.asArrow / .ripple / .trail / .aperture`，不是第二份默认值。
3. **`editorSettings.ts:263` 不是默认值对象，是转换函数**（`readCursorAperture(...)`）。

于是改动是 6 个点，一次到位：

| 位置 | 改动 |
|---|---|
| `ProjectAppearanceDefaults.cursor` | `shortcutOverlay: ShortcutOverlaySettings` |
| `DEFAULT_PROJECT_APPEARANCE.cursor` | `shortcutOverlay: DEFAULT_SHORTCUT_OVERLAY` |
| `CursorVisualSettings`（`types.ts:286`） | 同上，加字段 |
| `DEFAULT_CURSOR_SETTINGS` | 引用 `DEFAULT_PROJECT_APPEARANCE.cursor.shortcutOverlay` |
| `LegacyShape`（`cursorShortcutOverlay?: unknown`） | 落盘键 |
| 转换 / 写入 / 预设读写 | `readShortcutOverlay` + `next.cursorShortcutOverlay` + 预设透传 |

外加 `readShortcutOverlay()`：逐字段上下界（时长 300–6000 ms、字号 0.02–0.12、透明度 0.1–1、圆角 0–40），
颜色走既有的 `isRippleColour`，未知 position 回落默认。**缺失即关闭**，旧工程画面不变。

tsc 随后精确点出了 5 个测试 fixture 缺字段（`style-preset-service`、`nativeBridge.presets`、
`stylePresets`、`stylePresetsEditor`、`browserShim.presets`），逐个补齐——这次是编译器告诉我位置，
不是我在猜。

## 4. 真实素材与闭环证据

素材是任务书提到的那份真实录屏：`os-v27-rec2/recordings/recording-1794219210593.mp4`
（15.02 s，2880×1800，60 fps），其 sidecar 里有**真实采集的** `Ctrl+Alt+F9 @ 7489 ms`。
没有手写 JSON 冒充录制。

设置：`enabled: true`、`durationMs: 2000` → 卡片应在 **7.489–9.489 s** 之间在屏。

### 4.1 预览（真实 Electron，seek 用画布矩形）

| 时刻 | 请求 | 播放头 | 卡片区深色占比 |
|---|---|---|---|
| 6.5 s | 6.5 | 6.5 | 0.0037 |
| **7.6 s** | 7.6 | 7.6 | **0.0226** |
| **9.0 s** | 9.0 | 9.0 | **0.0226** |
| 10.0 s | 10.0 | 10.0 | 0.0037 |
| **7.6 s（反向回）** | 7.6 | 7.6 | **0.0226** |

截图确认卡片内容就是 `Ctrl+Alt+F9`（白字、深底、底部居中）。
反向回到 7.6 s 与首次的像素差 **9860 px，与首次完全相同**——没有残影、没有重播入场。

### 4.2 H.264 MP4（`v28-h264.mp4`，902 帧，2.1 MB）

| 时刻 | 卡片区深色占比 |
|---|---|
| 6.5 s | 0.0050 |
| **7.6 s** | **0.0382** |
| **9.0 s** | **0.0382** |
| 10.0 s | 0.0050 |

7.6 与 9.0 完全一致、6.5 与 10.0 完全一致：开关是干净的阶跃，不是渐变的巧合。

### 4.3 关闭浮层后重新导出

`enabled: false` → 同一时刻 7.6 s：**0.0050**（回到无卡基线），与开启版差 **22 560 px（1.088%）**。

至此任务 A 的四条硬条件（预览可见 / MP4 可见 / 区间准确 / 反向正确 / 关闭消失）全部达成。

## 8. 已知限制

1. **圆角没有**：`SceneAnnotation` 的文本框没有 radius 字段，卡片是矩形。按任务书"不为装饰重写 shader"保留。
2. **淡入淡出**：卡片是硬切（`animation: null`），`settings.opacity` 目前**没有作用到场景**——文本框的
   alpha 不在 `SceneAnnotation.text` 的字段里。这是真实缺口，未伪装成已实现。
3. **Speed 语义**：卡片时长按**源时间**算。2× 变速下它在成片里只停留 1 s（设置的 2 s 对应源时间 2 s）。
   任务书倾向"按成片时间"，这一点**尚未实现**，需要 scene 侧的 programme 换算，已记录未做。
4. **UI 未做**：设置只能通过项目文件修改。面板需要 14 个 locale 的 i18n key，未做。
