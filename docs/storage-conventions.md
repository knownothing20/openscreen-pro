# 存储约定（Storage conventions）

这份文件规定三类东西各自放在哪里、留多久、谁能删。起因很直接：V2.7–V2.8 期间构建产物累积到
26 GB、测试素材散在 `%TEMP%` 下用随机名字、录屏目录靠人记着——没有一处是"设计出来的位置"。

规则只定三件事：**录屏是资产、构建产物是缓存、测试素材是可再生的垃圾**。

---

## 1. 录屏（用户资产）—— 不自动删，不进仓库

| 项 | 值 |
|---|---|
| 位置 | `%APPDATA%\openscreen\recordings\`（`RECORDINGS_DIR`，代码固定） |
| 命名 | `recording-<epochMs>.mp4` + `.mp4.cursor.json` + `.session.json` |
| 进 Git | **不**。`.gitignore` 之外，也从不往仓库里拷 |
| 自动清理 | **不**。任何脚本都不许删这个目录 |

理由：录屏是唯一**不可再生**的东西。工程文件只存路径引用，一段录屏删了，引用它的工程就打不开了。
CS 缓存、构建产物、导出结果都能重来，录屏不能。

要做清理，只有一条路：**先扫工程引用，只提示"没有任何工程引用的录屏"**，由用户逐条确认。
在那之前，这个目录不进任何自动流程。

## 2. 构建产物（缓存）—— 只留最近两代

| 位置 | 内容 | 策略 |
|---|---|---|
| `release/<semver>-<purpose>/` | unpacked + NSIS，每代 550–930 MB | **只留最新一代 + 上一代** |
| `dist/` | renderer 构建输出 | 可随时重建，不备份 |
| `dist-electron/` | main/preload 输出 | 同上 |
| `release/*.yml`、`*.blockmap` | 更新清单 | 跟随最新一代保留 |

命名要能看出是哪一版、干什么用的：`v272-final3`（V2.7.2 第三次、终版）、`v28-unpacked-smoke`。
不要出现 `v25-build`、`v231-installer` 这种看不出内容的目录名。

**保留两代的原因**：出问题时要能说"上一版是好的"。留一代不够对比，留三代就是纯占地方——
26 GB 就是这么攒出来的。

清理入口：`npm run artifacts:clean`（默认只列清单，`--apply` 才动手）。

**例外**：脚本按修改时间保留最新两代，它不可能知道"某个包已被判定作废"。V2.7.2 的
`v272-final2` 就是这种情况——打进去的是一份带探针 chunk 的构建，已由 `final3` 取代。
这种包由人从清单里手动剔除，不要指望脚本猜。

## 3. 测试素材（可再生）—— 统一根目录，不用 Temp

`%TEMP%` 的问题是：随机名字、看不出谁建的、没人敢删、系统还可能在别处清理它。测试素材统一放：

```
D:\OpenScreen-Test\
├── userdata\<scenario>\      隔离的 Electron userData（--user-data-dir）
├── media\                    自己造的测试片，配一个 .json 记生成参数
└── out\                      导出结果，可随时重跑
```

约定：

- 目录名写清场景，不用 `os-v27-xxx` 这种只有作者认得的缩写；
- `media/` 下单个文件超过 200 MB 时，同目录写一个 `<name>.json`：怎么生成的、用来测什么、能不能重建；
- 用 `--user-data-dir` 隔离测试时，就近放 `userdata/`，**不要**污染真实 `%APPDATA%\openscreen`；
- 这些内容一律不进 Git（`.gitignore` 已覆盖 Temp 与 release，新根目录也要加）。

真实录屏**不许**拷进 `D:\OpenScreen-Test\media\`——那是资产，留在录屏目录，测试工程引用原路径。

## 4. 报告里的证据 —— 数字优先，图片限量

报告要的是**结论和数字**（"差 31.54% 像素"），不是把 MP4 塞进仓库。

- 报告里写：像素占比、毫秒、条数、SHA256；
- 需要留图时放 `docs/reports/assets/<报告名>/`，单张 ≤ 300 KB、整个目录 ≤ 5 MB；
- 视频、安装包、模型、addon **一律不进 Git**。

## 5. 谁负责

| 场景 | 动作 |
|---|---|
| 一次打包完成后 | 跑 `npm run artifacts:clean`，按提示删掉上上代 |
| 一次验收完成后 | 删掉 `D:\OpenScreen-Test\out\` 里的导出，保留 `media/` 里还要复用的素材 |
| 换版本 | 新目录 `release/<new>-<purpose>`，不覆盖旧目录（覆盖就没法回退） |
| 觉得占地方 | 先看这份文件，再决定删哪一类——**录屏永远最后考虑** |

## 6. 现状（2026-11-12 清理后）

| 位置 | 大小 | 说明 |
|---|---|---|
| `%APPDATA%\openscreen\recordings` | 112 MB | 5 段真实录屏，**不动** |
| `release/` | 26 GB | 待按"留两代"收敛（脚本已就绪） |
| `dist` + `dist-electron` | 89 MB | 可删可重建 |
| `%TEMP%\os-v272` | 4 MB | 遗留驱动脚本，下次验收后清 |
